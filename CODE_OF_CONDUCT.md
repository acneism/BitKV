# Code of conduct

CasketDB follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in the repository, its issues and pull requests, and wherever you speak for the project.

Report unacceptable behavior to the maintainer at d_kinisbek@kbtu.kz. Every report is reviewed and the reporter's identity is kept private. The maintainer decides on the response, from a warning to a ban from the project, as the Covenant's enforcement guidelines describe.

Report security vulnerabilities as [SECURITY.md](SECURITY.md) describes, not to this address.
